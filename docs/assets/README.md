# Demo assets

Media is intentionally not fabricated in the repository. Capture and add the
following files when the product flow is ready:

- `demo.gif`: screen recording of signup, creating an alert, triggering it, and
  seeing the email arrive in Mailpit.
- `dashboard.png`: screenshot of the trace list.
- `alerts.png`: screenshot of the alerts page.

## Capture instructions

On macOS, use any of:

- `Cmd+Shift+5` for a screen recording or screenshot.
- QuickTime Player for a screen recording.
- [Kap](https://getkap.co/) for a lightweight GIF recording.

Keep recordings focused on the product UI. Remove personal data and API keys
before committing. Optimize images and keep the GIF short enough for the README.
